## Автономная рабочая цепочка

- [x] Telegram webhook указывает на Cloudflare Worker.
- [x] Неверный секрет отклоняется с HTTP 403.

- [x] Основная очередь имеет одного producer и одного consumer.
- [x] Настроена отдельная dead-letter queue.
- [x] После переключения `pending_update_count` уменьшился с 10 до 0.
- [x] `last_error_date` и `last_error_message` отсутствуют.
- [x] Журналы Yandex Function подтверждают последовательную обработку накопленных обновлений без ошибок.
- [x] Компьютер пользователя и VPN не участвуют в рабочей цепочке.
